# Hospital login design

Preserve the hospital logo, institutional blue palette, and existing login request/session logic.

- Give the access form a quiet, high-contrast reading surface.
- Use a clear two-column desktop composition and a stacked mobile layout.
- Keep the left panel decorative and low contrast so it never competes with credentials.
- Treat labels, inputs, focus states, loading states, and error messages as first-class clinical safety cues.
- Use only subtle abstract imagery; never put patient data, medical claims, or readable text into decorative imagery.
- Verify the page at desktop and mobile widths after styling.
